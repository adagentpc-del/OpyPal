Enhance my existing A3 outbound email CRM with offer routing and conversion logic so that contacts are automatically classified and routed to the best next action based on behavior, engagement score, segment, and campaign context.

OBJECTIVE

I want the CRM to do more than send emails.
I want it to function like a lightweight sales intelligence and routing engine.

The system should:
1. detect which leads are cold, warm, or hot
2. route them to the correct next step
3. surface high priority opportunities in the dashboard
4. support different CTAs or next actions based on behavior
5. help me focus manual time only where it has the highest ROI

PRIMARY BUSINESS GOAL

The routing logic should help me identify:
1. leads that need continued nurture
2. leads that are showing interest and should receive a stronger CTA
3. leads that are hot enough for direct outreach, a meeting, or a higher value conversation

CORE ROUTING PRINCIPLE

Do not treat every lead the same.
Use engagement behavior plus contact context to determine what should happen next.

ROUTING RULES

1. Cold leads
If a lead has low engagement and no meaningful interaction:
- keep in the normal sequence
- if sequence completes without engagement, move to reactivation_pool
- keep visible in analytics but do not over prioritize

2. Warm leads
If a lead opens and clicks, or otherwise reaches warm tier:
- set routing_state = warm_followup
- flag in dashboard
- allow a stronger CTA to be used in later follow up steps
- optionally move to a warm specific micro sequence
- surface them in a “Needs Review” queue

3. Hot leads
If a lead replies, clicks multiple times, or reaches hot tier:
- set routing_state = hot_priority
- flag as high priority
- pause automation if reply is detected
- surface in a high priority queue
- create a manual follow up recommendation
- optionally show recommended next action such as direct outreach or meeting request

4. Sequence completed with no engagement
- set routing_state = reactivation_pool
- preserve for long term follow up
- include in reactivation dashboard views

5. Bounce or unsubscribe
- set routing_state = disqualified
- suppress from future outreach

6. Manual override
Allow admin to manually change routing_state and lock it if desired

PSEUDO RULES TO IMPLEMENT

If bounce or unsubscribe:
routing_state = disqualified
recommended_next_action = archive

Else if reply detected:
routing_state = awaiting_manual_outreach
recommended_next_action = manual_followup

Else if engagement_tier = hot:
routing_state = hot_priority
recommended_next_action = direct_manual_outreach

Else if engagement_tier = warm:
routing_state = warm_followup
recommended_next_action = send_capabilities_overview or manual_review

Else if sequence_status = completed and score <= 2:
routing_state = reactivation_pool
recommended_next_action = reactivation_later

Else:
routing_state = standard_nurture
recommended_next_action = continue_sequence
