Add an “Outreach Queue” to A3 Sales OS so daily outbound execution is fast and organized.

Purpose:
Create a dedicated workspace for daily outreach actions based on imported leads, generated drafts, and follow-up timing.

Add a new main navigation section called:
Outreach Queue

Requirements:

1. SECTIONS / VIEWS
Create 3 default queue views:
- New Imports
- Follow-Ups Due Today
- Overdue Follow-Ups

Optional extra view if easy:
- Awaiting Reply

2. DATA LOGIC
Populate the Outreach Queue from CRM lead records using these rules:

New Imports:
- leads with Status = New Lead
- prioritize most recently imported first

Follow-Ups Due Today:
- leads where Next Follow-Up Date = today
- exclude Closed Won and Closed Lost

Overdue Follow-Ups:
- leads where Next Follow-Up Date is before today
- exclude Closed Won and Closed Lost

Awaiting Reply:
- leads with Status = Contacted
- or Next Step = Awaiting reply

3. CARD / ROW DISPLAY
For each lead in the Outreach Queue, show:
- Company Name
- Contact Name
- Title
- Email
- Pipeline (Event or Agency)
- Status
- Next Step
- Next Follow-Up Date
- Source
- generated email draft preview if available

4. ACTIONS FOR EACH LEAD
Add action buttons:
- Generate Draft
- Copy Email
- Send via Outlook
- Edit Draft
- Mark as Contacted
- Snooze
- Skip
- Open Full Lead

5. SEND VIA OUTLOOK BEHAVIOR
Keep the current mailto-based Outlook flow:
- opens default email client with To, Subject, Body prefilled
- after click, ask: “Did you send this email?”
If yes:
- set Status = Contacted
- set Last Contact Date = today
- set Next Step = Awaiting reply
- set Next Follow-Up Date = 2 business days from today
If no:
- do not update the lead

6. FOLLOW-UP ACTIONS
Add quick action buttons:
- Follow up tomorrow
- Follow up in 2 business days
- Follow up next week
- Custom date

These actions should update Next Follow-Up Date and Next Step appropriately.

7. SNOOZE / SKIP
Snooze:
- pushes Next Follow-Up Date forward by 1 business day
Skip:
- leaves lead unchanged but moves to next item in queue

8. SORTING / FILTERS
Allow sorting by:
- newest imported
- oldest follow-up due
- highest deal value
- pipeline type

Allow filtering by:
- Event
- Agency
- Source
- Location
- Status

9. BATCH ACTIONS
If feasible, allow selected leads to:
- Generate Drafts
- Mark as Contacted
- Set Follow-Up Date
- Export Selected

10. UI / UX
Make Outreach Queue feel like a daily action dashboard:
- clean card or table layout
- obvious priority highlighting
- overdue items in red
- due today in yellow or blue accent
- mobile-friendly
- fast to scan and act on

11. PRESERVE EXISTING SYSTEMS
Do not break:
- Dashboard
- Leads / CRM
- Pipeline
- Tasks
- Templates
- Assets
- CSV Upload / Import

12. SMART BEHAVIOR
If a lead has no draft yet, show Generate Draft prominently.
If a lead already has a draft, show preview + Copy + Send via Outlook.
If a lead is overdue, visually flag it.
If a lead is New Lead and imported from ZoomInfo, prioritize draft generation.

13. FINAL QA
After building, test:
- queue population rules
- draft generation
- Send via Outlook behavior
- status updates
- follow-up date updates
- sorting and filters
- mobile usability

Then output a short summary of:
- what was added
- what was fixed
- any recommended next upgrades
