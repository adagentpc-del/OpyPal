Build a task and sales alert layer for the A3 Sales OS CRM.

Primary objective:
Once the Smart Follow Up Engine is live, I need the CRM to create operational next steps automatically so I do not miss warm or hot leads.
When someone clicks, replies, opens repeatedly, or hits another meaningful engagement threshold, the system should create follow up tasks, priority flags, reminders, and alerts so I can act quickly.

This task and alert layer must integrate with:
- Smart Follow Up Engine
- lead activity timeline
- campaigns
- sequences
- scheduled emails
- engagement events
- Outlook notifications or reminders if feasible later

Build the following:

Create a task model and task UI for lead based sales follow up.

Each task should support:

  - reschedule outreach
  - verify bounced email

  - custom

2. Auto task creation rules
Allow the CRM to create tasks automatically based on engagement and workflow events.

Ship with these default rules:

Rule 1:
If reply received
- create task: Review reply and respond
- priority: high
- due: as soon as possible or within same day

Rule 2:
If clicked but no reply
- create task: High intent lead follow up
- priority: high

Rule 3:
If opened multiple times without reply
- create task: Warm lead manual follow up
- priority: medium or high

Rule 4:
If bounce detected
- create task: Verify email and contact data
- priority: medium

Rule 5:
If lead reaches engaged or high intent score threshold
- create task: Personal outreach recommended
- priority: high

Rule 6:
If sequence paused due to reply
- create task: Continue conversation manually
- priority: high
