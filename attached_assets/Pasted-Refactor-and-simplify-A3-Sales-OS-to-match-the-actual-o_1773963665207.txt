Refactor and simplify A3 Sales OS to match the actual outreach workflow we are using.

PRIMARY GOAL:
Clean up the CRM so it only shows and requires the essential lead fields for CSV import and daily outreach, while improving the email workflow inside Leads / CRM.

========================================
1. CLEAN UP CSV IMPORT + CRM FIELDS
========================================

Update the CSV import flow so the only required columns are:

- Company Name
- Contact Name
- Phone
- Email
- Location

All other fields should be optional or auto-generated by the app.

For imported leads, auto-fill these defaults:
- Source = ZoomInfo
- Status = New Lead
- Next Step = Initial outreach
- Next Follow-Up Date = tomorrow

Auto-generate or infer when possible:
- Pipeline:
  - Event for hotels, venues, convention centers, hospitality/event-related businesses or titles
  - Agency for agencies, experiential firms, creative/marketing businesses or titles

If no clear match is found, default Pipeline to:
- Event

Update the CSV import UI to:
- show a preview before import
- allow simple column mapping if headers differ
- require only the 5 essential fields above
- skip duplicate leads by matching email OR company name + contact name
- show a clean import summary:
  - rows uploaded
  - imported
  - duplicates skipped
  - drafts available/generated

========================================

Clean up the Leads / CRM table so the default visible columns are only:

- Company Name
- Contact Name

Move less-used fields out of the main table and into the lead detail drawer/modal under an “Additional Details” section, including:

- Deal Value Estimate

Keep the CRM visually clean, easy to scan, mobile-friendly, and optimized for daily outreach execution.

========================================
3. EMAILING FROM LEADS / CRM VIEW
========================================

In the Leads / CRM view, when opening a lead, add a clear outreach/email section.

For each lead, add these actions:
- Select Template
- Preview Email
- Copy Email
- Send via Outlook
- Mark as Contacted

Add a template selector dropdown populated from the existing Templates section.

When a template is selected:
- auto-fill the email subject and body using that template
- replace placeholders like:
  - [First Name]
  - [Contact Name]
  - [Company Name]
  - [Name]
with the lead’s data where possible

If no first name can be isolated, use Contact Name.

Allow the generated email to be edited before sending.

========================================
4. ASSET ATTACHMENT / CAPABILITIES DECK SUPPORT
========================================

In the same outreach/email section for each lead, add the ability to attach or associate an asset before sending.

Requirements:
- show a dropdown or selector of uploaded assets from the existing Assets section
- allow selecting one or more assets to associate with the email
- especially support attaching/selecting the capabilities deck
- show selected asset names in the email activity/log

Important:
Because the current send flow uses Outlook via mailto, do NOT try to physically attach files through mailto if that is not technically reliable.
Instead:
- show the selected asset(s) in the CRM log
- include a note in the UI such as:
  “Selected asset(s) to send: [Asset Name]”
- if feasible, include asset links in the draft body when assets have URLs
- if assets are local/internal only, still log them as selected/sent materials

========================================
5. SAVE WHAT WAS SENT IN CRM HISTORY
========================================

For each lead, create an outreach history / activity log section.

Whenever the user sends via Outlook and confirms “Yes, I sent this email,” save the following into that lead’s history:

- date/time sent
- template used
- final subject line
- final email body snapshot
- selected asset(s)
- action type = Email Sent
- sender = Alyssa / current user

This should be viewable later inside the lead detail view under:
- Outreach History
or
- Activity Log

If the user clicks “No” after Send via Outlook, do not mark it as sent and do not log it as Email Sent.

========================================
6. STATUS UPDATES AFTER EMAIL SEND
========================================

After “Send via Outlook” is clicked, keep the confirmation:
- “Did you send this email?”

If YES:
- set Status = Contacted
- set Last Contact Date = today
- set Next Step = Awaiting reply
- set Next Follow-Up Date = 2 business days from today
- save the outreach history entry
- save template used
- save selected asset(s)

If NO:
- do not update the lead
- do not save sent history
