Build the next stage of my A3 outbound email CRM inside the existing Replit app.

Objective:
Turn the current template plus CSV upload CRM into an automated outbound sequence engine.

Core behavior:
1. I upload a CSV file daily
2. The system validates and imports each row as a contact
3. If the contact does not already exist in an active sequence, enroll them automatically
4. Automatically send the first email in the selected sequence
5. Automatically schedule all future follow ups
6. Pause the sequence immediately if a reply is detected
7. Prevent duplicate active enrollments for the same email
8. Allow long term reactivation touches at 4 months and 6 months
9. Show all activity in an admin dashboard

Create a sequence engine that supports:

step 2 follow up on Day 3
step 3 follow up on Day 7

step 7 reactivation on Day 180

C. CSV upload workflow
When CSV is uploaded:
1. map headers automatically
2. validate email addresses
3. remove invalid rows
4. deduplicate within the file
5. deduplicate against existing contacts in database
6. if email exists and sequence_status is active, skip re enrollment
7. if email exists and is completed or paused, allow optional re enrollment toggle
8. assign selected campaign and selected template sequence
9. queue the first email
10. create future scheduled sequence records

D. Email sending
Integrate with Outlook / Microsoft Graph for sending from my working outreach inbox.
Each outbound email should:
1. send from the connected mailbox
2. log sent status
3. store message id if available
4. update contact current_step
5. update last_email_sent_at

E. Scheduler
Create a scheduler job that runs automatically every day and:
1. finds all due sequence steps
2. only sends on business days
3. only sends during a defined send window
4. respects daily send caps
5. adds slight randomized spacing between sends
6. skips contacts marked do_not_contact, replied, bounced, or unsubscribed
7. sends the next due step and updates logs

F. Reply detection
Create reply detection logic using the connected Outlook inbox.
If a reply is detected from a contact email:
1. set sequence_status to paused_replied
2. cancel all future scheduled steps
3. show the contact in a replied queue on dashboard
