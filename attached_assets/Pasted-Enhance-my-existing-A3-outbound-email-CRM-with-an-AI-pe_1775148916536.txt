Enhance my existing A3 outbound email CRM with an AI personalization layer that generates a custom first line for each contact during CSV import or before email send.

OBJECTIVE

I want the system to automatically generate a short, relevant, professional personalized line for each contact so outreach feels more intentional and less mass sent.

This personalization must be operationally efficient, safe, editable, and optional. It should improve reply rate without making the workflow complicated.

PRIMARY USE CASE

When I upload a CSV of leads, I want the system to be able to create a custom_line for each contact using the data already available in the CRM and CSV.

The custom_line should be usable in templates as {{custom_line}}.

EXAMPLE OUTPUT TYPES

Examples of acceptable custom_line outputs:
I noticed your team appears to be investing in experiential growth this year.
It looks like there may be an opportunity to strengthen on site brand execution across upcoming initiatives.
Given your role, I thought this might be relevant as visual execution often affects both experience and operational consistency.
With the type of projects your team appears to be involved in, timing on signage and fabrication can make a meaningful difference.

These must remain general enough to be safe, but personalized enough to feel thoughtful.

If some fields are missing, the personalization engine should still work using what is available.

AI PERSONALIZATION REQUIREMENTS

1. Generate one short custom_line per contact
2. Keep it concise, ideally 1 sentence
3. Make it sound professional, commercially relevant, and natural
4. Do not fabricate precise facts that are not in the data
5. Do not invent recent news or specific company events unless explicitly provided in the source data
6. If personalization confidence is low, generate a safe generic line instead
7. Allow admin to review or regenerate custom_line before launch if desired
8. Store the final custom_line on the contact record

FALLBACK LOGIC

If there is enough data:
Generate a stronger personalized line

If data is limited:
Generate a softer generalized line relevant to the segment or title

If almost no data exists:
Generate a neutral fallback line such as:
I thought it made sense to reach out given the type of work your team may be evaluating.
or
I wanted to reach out as this may be relevant to your team depending on current priorities.

Do not leave custom_line blank unless admin disables personalization.

PROMPT ENGINE LOGIC

Create an internal prompt builder that uses available contact data to construct an LLM prompt for generating custom_line.

Internal AI instructions should enforce:
1. one sentence only
2. no hype
3. no fake specificity
4. no awkward buzzwords
5. no em dashes
6. no mention of scraped data
7. no mention of private research
8. no excessive flattery
9. no claims that cannot be supported by the provided contact data

PERSONALIZATION MODES

Create 3 selectable personalization modes in admin settings:

1. Off
No custom_line generated

2. Safe
Generate soft, generalized personalization using only obvious available fields

3. Enhanced
Generate stronger but still safe personalization using title, segment, intent_signal, why_selected, and company context from CSV

DEFAULT MODE

Set default personalization mode to Safe
