OBJECTIVE

TECH STACK

CORE DAILY WORKFLOW

1. I upload a CSV file
2. The system maps headers and validates rows
3. The system removes bad rows and duplicates
4. The system checks whether each contact already exists
5. If the contact is not already active in a sequence, enroll them
6. Assign the correct campaign and template set
7. Automatically send the first email
8. Automatically create and schedule all future follow ups
9. Scheduler runs daily and sends all due sequence steps
10. If a contact replies, pause all future emails for that contact
11. If a contact does not engage, send long term reactivation emails later
